# Suporte

## Canais de atendimento

| Canal | Uso |
|---|---|
| [Issue de Suporte](../../issues/new?template=suporte.yml) | Solicitações técnicas e operacionais (interno) |
| [Site](https://teranex.inf.br) | Informações gerais e contato comercial |
| [E-mail](mailto:contato@teranex.inf.br) | Contato direto com a equipe |

## Reportar vulnerabilidade de segurança

**Não abra uma issue pública para vulnerabilidades.**
Siga o processo descrito em [SECURITY.md](SECURITY.md).

## Antes de abrir uma issue

- Verifique se já existe uma issue aberta sobre o mesmo problema
- Consulte a documentação do repositório (README, wiki)
- Para bugs, tenha em mãos logs e passos para reproduzir

## SLA interno

|---|---|
